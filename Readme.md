# BancaIP

Teste de equipamentos de rede via CLI. Simples, objetivo e informativo.

O BancaIP trás funcionalidades combinando automação e fácil utilização voltadas para testes de mesa de equipamentos de borda de rede (roteadores, *bridges*, ONUs ou ONTs). O ambiente por linha de comando é leve podendo ser utilizado em qualquer configuração de máquina. Tendo conexão Ethernet LAN é o necessário.

Para utilizar, baixe o executável presente em Releases com a Label ST: BancaIP(ST) (abreviação de *stable*).

Em caso de colaboração acesse em *Collab*. Os arquivos Enviroment.md e Tests.md apresentam guias de como deixar o ambiente adequado para testar os requisitos sugeridos na sua PR.
